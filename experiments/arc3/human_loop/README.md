# 人間の予測を更新する探索回路 v0.2

実人間の観測 → 分布・観測条件の候補生成 → 学習 → 未使用グループへの予測 → 外れ方を記録 → 複数の仮説を保持 → 次の候補、という回路です。公開ゲームの平均点を研究上の採用条件にしていた v0.1 の外側に、人間予測を中心とする経路を追加します。公式提出は手動のままです。

この版が予測するのは観測可能な行動と待ち時間です。「何に気づいたか」は直接の正解ラベルがない潜在変数です。画面の停滞や行動反復を予測用の手掛かりにしますが、認知状態を同定したとは扱いません。画像中の物体・規則を意味的に理解するモデルの実装は今後の接続点です。

## 実データと観測単位

| 系列 | 予測 | 分割単位 |
|---|---|---|
| ARC Prize公式公開リプレイ | 次の操作ID、次レベルを初めて達成するまでの手数 | 環境単位 |
| 研究室2人CPR | 次の記録時点への移動方向、次の収穫までの秒数 | 組単位、条件・ラウンドをまとめる |
| DeCaroほか・Janssen共著2024 | 次の移動方向または収穫、次の記録イベントまでの秒数 | 実験セッション単位、全ラウンドをまとめる |

ARC公開記事は342件、取得した4月16日版ZIPには340リプレイがあります。g50tは記事14件・ZIP12件です。ファイルから得た件数を正本とし、2件を捏造・補間しません。342や研究全体の458人を取得済み参加者数として表示しません。GUIDはリプレイIDであり個人IDの同一性が保証されないため、参加者単位で独立した評価とは呼びません。ゲーム版の一覧もmanifestに保存します。

研究室ZIPでは `04_data/Comp` と `04_data/Coop` の157ラウンド、20組を使い、`03_rawdata`との重複を除外します。PlayerのCSVはキー入力ではなく座標の時系列、HarvestのCSVは収穫イベントです。Janssen系列はOSF公開 `raw-data.zip` の32セッション、練習を除く288ラウンドを使います。異なる観測形式を同じ「行動数」に合算して性能を報告しません。

研究室の原本、Janssenのチャット・ネットワーク情報・UUID、ARCのリプレイGUIDはモデルやGitHubに含めません。派生配列には列挙した数値特徴と分割用の整数のみを保存します。原本ZIPはローカルの入力として保持します。

## 分布と探索

行動分布はDirichlet平滑化した頻度モデルで、無条件・前操作・進行段階・反復履歴という観測の組を替えます。条件別の学習、事前分布の強さ、温度、反復を選ぶ線形傾斜も探索します。これは少数の解釈可能な仮説を比較する基礎実装であり、LLMによる自由なプログラム発明ではありません。

待ち時間には経験分布、対数正規、対数ロジスティック、Weibull、四次エネルギーの5族を使います。四次族は標準化した対数時間zに対して

`E(z) = z^4/4 + r*z^2/2 - u*z`, `p(z) ∝ exp(-β E(z))`

を正規化します。rを負にして二つの山を持つ候補も生成します。[-7,7]・1401点の有限積分による統計模型です。λは1に固定、位置と尺度は学習し、r,u,βを探索します。エラスティカの全定理や人間の認知機構をこの分布から主張しません。

全候補は保存します。次の候補の親には、3系列×2予測の6つの誤差によるPareto集合、条件別の最良候補、予測が離れた候補を使います。最初の10候補で5分布族と2段階の履歴を覆い、その後3回に1回は上位候補に依存しない新規抽出をします。それ以外は保持した候補の2項目を変異させます。改善しない回数による早期打切りはありません。低い平均成績だけを理由に仮説を消しません。

## 評価と未解決の扱い

グループを最初に約60%学習・20%探索用検証・20%最終評価に分け、固定seedと分割一覧を記録します。探索中に最終評価の正解は使いません。検証データを繰り返し参照することによる適応的な過適合は残るので、`seal`で選抜と重みを固定してから最終評価します。全保持候補を等重みで混合した分布も最終評価し、成績を見て重みや候補を変更しません。seal後に同じ実験への探索追加は拒否します。

行動の対数損失・Brier score・正答率・確信度ビン、待ち時間の対数損失を保存します。主指標はグループごとの平均損失をさらに平均したものです。長い記録が平均を独占しないようにし、観測数で加重した平均、条件別・最悪グループの値も併記します。系列間で単位の違う対数損失を直接合算しません。

待ち時間は、ARCでは1から2倍刻み18境界、秒数では0.125から2倍刻み18境界に固定してビン確率を比較します。未解決の最終レベル・研究室の最後の収穫待ちは右打切りです。打切り位置はそのビンの下端までに保守的に丸め、そこから右の確率を尤度にします。成功した人だけを学習して失敗を消す扱いはしません。ただし途中離脱が難しさや気づきと関連する「情報を含む打切り」は、この版では識別していません。

Janssen系列では正確な最後の観測終了時刻を推定せず、次のイベントが記録された区間の正の待ち時間だけを使います。これは無条件の離脱・生存分布ではありません。同じミリ秒のイベント間隔は件数を記録して時間モデルから除外し、行動モデルには残します。CPR→ARCの移植性能はまだ検証していません。現在は同じ分布族を各系列で独立に学習しています。

## 資料との接続

ユーザー指定の三資料は `source-notes.json` に元ファイル・SHA-256と接続範囲を記録します。

- 二変数の選び方の比較：状態・係数・入力のどれを動かし何を固定したかを候補specに残す。15組の可逆性分類そのものを統計的な同定保証にしない。
- 線形入力の実験帳：`-u*x`による分布の傾斜、一つ／二つの井戸を候補にする。同じ状態での二測定という前提のない実ログに、座標復元の公式をそのまま適用しない。
- 検証と再実行：正のβによる指数重みを正規化して使用する。エネルギーの大小関係、確率予測の良さ、探索の価値は別の量として記録する。

GPU基準の公式Public Score **26.20**（提出57751913、COMPLETE、2026-10-29取得）は `official-reference.json` に出典とreceiptのハッシュを保存します。これは下流のARC成績の基準であり、人間の行動ラベルにも、CPRからARCへの転移の証明にも使いません。CPU基準0.35とGPU基準26.20は異なる系列です。

## 再実行

Python 3.12以上を推奨します。リポジトリのルートで実行します。

```powershell
python -m pip install -r experiments/arc3/human_loop/requirements.txt
python experiments/arc3/human_loop/fetch_sources.py --output build/human-data
python experiments/arc3/human_loop/data.py --arc-zip build/human-data/arc-human.zip --lab-zip "C:/Users/Dalcia/Research/01_Models/CPR/files/02_expCPR_2player.zip" --janssen-zip build/human-data/janssen-raw.zip --output build/human-observations
python experiments/arc3/human_loop/engine.py run --dataset build/human-observations --output build/human-search --candidates 12 --seconds 3600
```

同じrunコマンドを再実行すると次の12候補へ進みます。毎回全履歴を照合し、データ・モデル・実行コードの変更を検出します。中断された純粋な数値計算は同じintentから再計算できます。出力フォルダーに`STOP`を置くと候補の境界で停止し、外して同じコマンドで再開します。時間上限は候補の境界で確認するため、現在の候補の計算時間だけ超過し得ます。OSロックにより同時書込みを防ぎます。常駐処理・定期実行は設定していません。

```powershell
python experiments/arc3/human_loop/engine.py seal --dataset build/human-observations --output build/human-search
python experiments/arc3/human_loop/engine.py forecast --output build/human-search --elapsed 64 --additional 64 --stage 0 --condition 0
python -B -m unittest discover -s experiments/arc3/human_loop -p test_human.py -v
```

forecastは「ここまで解けていない人間が次の予算内で次レベルに進む確率」の参考分布を返します。生存で条件づけた混合重みを使い、ビン内部は対数時間で補間します。モデル間の範囲は信頼区間ではありません。人間参照値をエージェント自身の成功確率と取り違えて自滅・撤退を強制する接続は入れていません。探索方策に組み込む際には、エージェントの成功・情報獲得・機会費用の予測を別に合わせます。

データ版やコードを更新して研究を続ける際は新しい出力フォルダーを使います。既に見た最終評価を再使用した結果は探索的な比較であり、新しい独立検証ではありません。公開デモ検証には隣の`autonomous`を使えます。公式提出APIを呼ぶコードはこのディレクトリーにはありません。

## 2026-10-29の実行結果

全48候補が完了し、23候補を保持しました。ARC 180,156操作／1,808レベル到達・打切り区間、研究室573,718座標遷移／22,782収穫間隔・打切り区間、Janssen 1,637,246行動／1,634,452正のイベント間隔を変換しました。これらは相関のある反復記録であり、独立した人数ではありません。取得ARC ZIPの成功リプレイは144件でした。

探索に使わなかった5 ARC環境・4研究室組・7 Janssenセッションで得たグループ平均の対数損失です。小さいほど良い値ですが、異なる予測間の数値は直接比較しません。基準は学習部分から作った無条件の経験分布です。

| データ | 次行動：基準 → 固定混合 | 待ち時間：基準 → 固定混合 |
|---|---:|---:|
| ARC | 1.601061 → 0.958313 | 1.704071 → 1.633319 |
| 研究室CPR | 1.098342 → 0.674079 | 1.926628 → 1.849195 |
| Janssen共著実験 | 1.595644 → 1.126199 | 1.350975 → 1.330378 |

同一データ上の単一分割での結果です。強い既存認知モデルとの優劣、転移、未知ARC攻略、公式スコアの上昇は検証していません。最終評価後に候補や重みを選び直していません。新規19・公開ループ19・既存採点サイクル74、計112テストが成功しました。実データで分割実行からの再開、STOP停止、sealの再実行で結果が変わらないこと、seal後の探索拒否も確認しました。
