# 120-Toffoli商加算の完全DQI統合

基準は検証済み42-Toffoli乗算統合版、DQI SHA-256
`252b41714f6147723e44082e4a4f75d84b34b5aa4b23e8c47ce096667caa75e9`。
静的Toffoli 3,804,126、Q=1,893、古典ビット49,155、名前付きレジスタ4,165。
Release v1.0、既存の候補と提出ZIPは変更しない。

GF(2^12)、多項式基底0x1053における契約は
`|den,num,t,c,0> -> |den,num,t XOR c*num*inv(den),c,0>`、inv(0)=0。
tは任意、cは量子制御。局所82線のうち入力37線、清掃対象45線。
全37入力変数・108独立測定変数の厳密ANF証明を実行し直す。
旧141版と新120版の出力、補助量子ビットと一時古典ビットの清掃、残留位相ゼロを確認する。

`quotient120_dqi.py`は基準SHAを固定し、forward/reverse各444箇所を全て監査する。
入口リセット72個と141版の全命令を、109量子線・13古典線の単射な対応で照合する。
27本は旧スキャフォールドの未使用線である。局所線への入口リセット順は
q57..68、q12..44、q82..108。古典一時ビットはb49140..49152のみ。
範囲をまたぐ外側の古典条件とブロック内PUSH/POPを拒否する。

旧局所命令[1492,2057)の無測定積だけを交換する。
q45..56（num）、q12..23（逆元）、q57..68（積先）に作用する。
旧63 CCX・481 CX・21 SWAP、新42 CCX・482 CX・0 SWAP。
この積は任意XOR先に対応し、古典制御・測定を含まない。
量子制御のXOR、HMR、位相補正、リセット、一時ビット清掃は前後で同一。
編集外の全バイナリ区間を照合し、古典ターゲットpacket 8、古典条件packet 9、
メタデータpacket 11は全体のバイト一致を要求する。
実配線は生成物のsite-map.jsonに全置換箇所分保存する。

まず1箇所の完全KMBを生成し、candidate → smoke → full-packageを実行する。
**1箇所版のfull-packageまで全てPASSした場合だけ**888箇所へ拡張する。
両候補はそれぞれ新しく102,400試行でfull検証する。
比較元のみ、SHAと全測定条件を照合した既存成功記録を再利用する。
比較元の計算時間は過去の測定であり、同じホスト上での比較ではない。

提出用候補ZIPはv1.0のDQIだけ交換し、13ファイル・他12ファイルのバイト一致と
検証対象DQIのSHA一致を監査する。Kaggle提出コマンドはない。
公開検証器のコストとKaggle公式スコアは別に報告する。
18,648の追加削減と最終3,785,478 Toffoliは、全体検証前は条件付き見積もりである。

実行結果はActionsのdqi-checkpoint-full-package、dqi-quotient120-unscored、
dqi-candidate-for-human-reviewに保存する。NOT_RUNをPASSとして扱わない。
