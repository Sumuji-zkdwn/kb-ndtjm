# inverse66を完全DQIへ組み込む実装記録

基準はRelease v1.0の13ファイル入り`submission.zip`。元のZIP・Release・mainは変更しない。
従来のWFS位相核1箇所置換とは別の候補で、Forney処理の逆元計算とその後始末を置換する。
局所核だけでなく、Sレジスタ70個・Eレジスタ4,095個を持つ完全な`dqi.kmb`を生成する。

## 保存する演算

体はGF(2^12)、多項式は`0x1053`、`inv(0)=0`。
既存の公開参照コードは各位置jで逆元`y=inv(sigma_prime)`を計算し、
`located = r * omega`（rはsigmaが0かを表す量子ビット）を使って

\[
(-1)^{\operatorname{parity}(E_j\mathbin{\&}(located\cdot y))}
\]

の位相を与え、yと作業領域を清掃する。積は体の乗算、E_jは12ビットの古典マスク。
E_j=0なら位相も0なので、既存のマスク非零条件でForney全体が省略される。
この条件と、その内側の位相演算そのものは保存する。

置換するのは逆元計算と対応する後始末の内部命令だけ。新しいforwardは66 CCXで逆元を計算し、
中間値を保持する。位相演算の後にeraseがHMRと条件付きZ/CZで出力・中間値を清掃する。
eraseにCCXはない。元の315+0を66+0へ置換するため、静的削減数は1箇所249である。

## 実際の対応

次は最初の1箇所の対応。全位置の対応は生成時の`site-map.json`に記録し、
各位置の実際のKMBオペランドから取得する。

| 用途 | 局所KMx | 既存DQIへの結線 |
|---|---|---|
| 逆元入力 | q0..q11 | q888..q899 |
| 初期値0の逆元出力 | q12..q23 | q1803..q1814 |
| 作業領域21個 | q24..q44 | q1828..q1848 |
| 元の作業領域48個 | ― | q1828..q1875 |
| 新しい一時測定ビット | b0 | b49154 |
| 元のForney実行条件 | 外側の条件 | b49153 |
| 位置jの古典マスク | 位相演算の係数 | b(12j)..b(12j+11) = E_j |

逆元出力12個と元の作業領域48個を初期化する、入口直前の60個のR命令を保存する。
新方式はそのうち21個だけ使うため、全回路のQ=1,893を維持できる。
古典ビット数は49,154から49,155になる。名前付きレジスタとその対応はバイト単位で保存する。
元の逆元ブロックが書いていた非公開の一時ビットは新ブロックの出口で清掃し、
Eマスクとb49153には書き込まない。

## 命令とバイナリの扱い

KMxでは`CX qA qB`、`CCX qA qB qC`、`HMR qA b0`、
`CZ qA qB if b0`、`Z qA if b0`を使う。
HMR結果に応じた位相補正を済ませてから一時古典ビットを消去する。
既存の外側のPUSH/POP条件は新命令にも適用される。

KMBはversion 2のSOA形式。命令コード配列と、量子・古典のオペランド配列を別々に置換する。
外側のINFO_TAGは残し、除去した逆元内部のINFO_TAGだけを詰め直す。
それ以外の命令・オペランドの範囲は元とバイト比較し、完全な候補をKickmixで再解析する。
入力ZIPと基準DQIのSHA-256が一致しない場合は処理しない。

## 証明と検証を区別する

- 局所の厳密ANF検査は、12個の入力、12個の位相係数、96個の独立HMR結果を変数とする。
  全2^96測定分岐について目的位相を保存し、出力・作業領域を0へ戻す。
  Pythonの有限代数検査であり、Leanによる証明ではない。
- 統合時は各位置について、入力・出力・作業領域の非重複、出力の初期化、
  呼び出し側による作業領域への非干渉、外側の条件とE_j対応を検査する。
- `audit_callers.py`は全4,095箇所の実命令を追加監査する。
  逆元出力を含む589,680個の位相命令は出力に関して一次であり、
  古い逆元の測定記録が呼び出し側へ漏れていないことを確認した。
- 1箇所版と全位置版は、ローカルのcandidate・Kickmix解析・公開公式verifierのsmokeを通過した。
  smokeは1,536ショット、値・位相の誤り0、log2_delta=-128。
  [Actionsのfull-package検証](https://github.com/Sumuji-zkdwn/kb-ndtjm/actions/runs/40200104339)も成功した。
  候補・基準とも102,400ショットで値・位相の誤り0、実測コストは約17.806%低減した。

生成済み全位置版の静的Toffoli数は4,705,806（元5,725,461）。
実測スコアの改善率とは区別し、fullでは同じ条件の基準回路と比較する。
必要な公式ファイルがなければ未実施（NOT_RUN）と記録する。
full-packageが通った場合だけ、残り12ファイルを基準ZIPから保持した候補ZIPを作る。
Kaggleへの提出コマンドは実行しない。

再現コマンドとSHA-256は[英語の詳細記録](README.md)を参照。

提出用ZIPは68,388,339 bytes、SHA-256は`a40089eebeef3aee605694e8443972839741c31f8e2a25ff6cb429d1f27c1457`。取得したActions成果物を別途照合し、13ファイルのうちDQI以外の12ファイルは基準と同一、DQIは検証対象のSHA-256と一致した。
