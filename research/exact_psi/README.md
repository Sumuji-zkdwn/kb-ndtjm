# Forney掃引のΨ化：厳密版と準厳密版の費用比較（2026-11-08）

PR8（DQI: Q=2,482、Toffoli相当 715,786、公開Public 1.66950）のForneyは、
4,095点それぞれで逆元・位相（68）と根判定（11）に計79 Toffoli相当を使う
（323,505、DQI全体の45%）。公開の `andigu/uncompute`（Gu et al., arXiv:2610.22367）は、
1ショットに1回だけ多項式Ψ（σ'Ψ ≡ 1 mod σ）を作り、各点を23 Toffoli
（根判定11＋根フラグ付きペアリング12）に下げている。ただしそのΨ計算は
測定した窓（係数の範囲）と、ゼロピボットの修復を1回までに限る固定スケジュールを使う近似である。

このディレクトリは「可変マスクのまま、厳密に23/点に近づける」案を、回路を書く前に評価した記録である。
**量子回路は作っていない。公開検証器・Kaggle採点は実行していない。**

## 1. 厳密な固定スケジュール（古典モデル）

`model.py` は GF(2^12)/0x1053 上のビット単位の古典モデル。

- σ = E² + zO²（E_i=√σ_2i, O_i=√σ_2i+1）と分け、m=⌊(35−L)/2⌋ だけ上へずらして deg E'=17 にする
  （奇数Lで σ_{L−1}=0 のときはE'とO'を交換）。ここまでは上流と同じ。
- 反転多項式に対し、Bernstein–Yang型の単項化divstep（δ>0かつg(0)≠0で条件付き交換、
  ピボット逆元でg(0)を消してxで割る）を**データに依存しない固定回数**だけ行う。
  δの初期値を0にして、最初の1回を「同次数の頂点消去」として扱う。
- 得られる x^N c = uF + vG を元の向きに戻すと A E + B O = c z^(17−m)。
  Ψ* = B² + zA² は各根βで Ψ*(β)σ'(β) = c² β^(2(17−m)) を満たす（定数cとβのべきは掃引側で吸収可能）。

`check()` はBezout恒等式と、全ての根での Ψ*σ' の値を毎回検査する。

### 必要なステップ数（全数検査）

`exhaust.py` の結果。異常な剰余列（次数が2以上落ちる・ゼロピボットが続く）を含め、
**全入力で 2d+1 ステップが必要十分**（d = W//2）。

| 体 | 最大重みW | 入力 | 必要ステップの最大 |
|---|---:|---|---:|
| GF(16) | 5 | 全4,943通り | 5 = 2d+1 |
| GF(16) | 7 | 全16,383通り | 7 = 2d+1 |
| GF(32) | 7 | 全3,572,223通り | 7 = 2d+1 |
| GF(32) | 9 | ランダム200,000 | 9 |
| GF(64) | 11 | ランダム100,000 | 11 |
| GF(4096) | 35 | 重み1..35をランダムに計2,800 | 35 |

本番（W=35, d=17）では35ステップ。アルゴリズムは体に依存しない形で書いており、
小さい体での全数一致を一般の根拠とする。Lean等の形式証明ではない。

### 最悪ケースの窓

`windows.py`。正常な剰余列では f, g の長さは2ステップごとに1語ずつ縮むが、
**異常列ではδが大きくなり、fが長さd+1のまま最初のdステップ近く残る**
（GF(16)全数：fの最大長 4,4,4,3,2,1,1）。固定回路の窓は最悪ケースで取る必要があるので、
厳密版の剰余パスは概算で次の通り：

- g ^= w·f の積：Σ min(d+1, 2d+1−n) ≈ 460回 × 42 ≈ 19.3k
- ピボット逆元 35×66、w の積 35×42、f,g の条件付き交換 ≈ 10.7k
- 合計 ≈ 34k（上流の前進パス 15.2k の約2.2倍）。余因子の再構成も同程度に膨らむ。

## 2. 費用モデル

`cost_model.py`。評価式は Khattar et al.（arXiv:2610.23832, 式45）の
S = R(ε⁺)·Q²·T, R(ε) = ln2 / −ln(½ + 2√ε)、ε⁺は102,400ショット・δ=2⁻¹²⁸の片側上限。
失敗0でもε⁺=8.66×10⁻⁴、R=1.1913（PR8の実測費用と一致）。
Rは√εでしか増えない：失敗1回で+0.46%、5回で+1.8%、14回で+4.1%。

Qを2,482のまま保てると仮定した場合（未検証）：

| 案 | T | 真の失敗率 | S（PR8比） |
|---|---:|---:|---:|
| PR8（現行） | 715,786 | 0 | 1.000 |
| Ψ化・上流規模のEuclid（準厳密） | 575,406（−19.6%） | 1e-5 | **0.807** |
| 同上 | 575,406 | 1.4e-4（上流の公表値） | 0.837 |
| Ψ化・厳密（Euclid ×2.0） | 664,346 | 0 | 0.928 |
| Ψ化・厳密（Euclid ×2.5） | 708,816 | 0 | 0.990 |

損益分岐はEuclid（往復）229,320 Toffoli、上流の2.58倍。
**厳密版は最悪ケースの窓のため利益が5〜7%程度に縮む。準厳密版は約19%削減が見込める。**

## 3. 判断と次の段階

- 「厳密に23/点」は費用面で割に合わない。評価式の√ε罰則は小さく、
  失敗率1e-5程度の準厳密Ψ（上流のEuclid構造、窓と修復スケジュールを本回路の重み法則で再測定）が最も有利。
- 可変マスクは障害にならない：ペアリングの行 r_a(λ) は λ に線形なので、
  WFS核と同じくEマスク条件付きCXで作れ、Toffoliは12のまま。上流のZ補間（71点削減）は固定マスク前提なので使わない。
- これはPR8の「保守的（厳密）」方針を変える判断なので、実装前に方針の確認が必要。
- 未確認：Q（Euclidの作業領域と保守的BMの35段スタックの同時生存）、窓の再測定による失敗率、
  完全回路の生成、Kickmixでの解析、公開検証器102,400ショット、Kaggle採点。
