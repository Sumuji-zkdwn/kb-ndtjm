# 次の方向：二値の制御と、消してよい情報の条件

2026-10-26 JST。既存のinverse66完全DQI候補を保存したまま、次の局所置換を検討する。
このディレクトリには局所回路と証明を置く。完全DQIへの生成器は
`quantum/eea_quotient_dqi.py`、段階別の結果は`checkpoints/`に保存する。

## 方針

値はGF(2^12)の12ビット表現を保持する。制御は「ゼロか」「次数が小さいか」
「停止したか」などのBoolean関数として記述する。GF(2^12)の値に実数の正負順序を
持ち込まない。量子制御ビットは重ね合わせを保ち、単に測定して古典分岐へ変えない。

古典状態xの要約q(x)だけで操作T_uを実行できる条件は、

\[
q(x)=q(y)\Longrightarrow q(T_u x)=q(T_u y)\quad(\forall u)
\]

である。さらに、必要な観測Oもq(x)から復元できることを要求する。
この条件は古典状態機械の要約に関するもので、量子回路の等価性には別途、
全測定分岐の位相と補助量子ビットの清掃を検査する。

Forneyで任意の12ビットマスクEに対してE・vのパリティを要求される場合、
すべてのEに共通する要約でvの異なる値を同一視することはできない。
Eを各標準基底ベクトルにすればvの各ビットが復元できるからである。
マスクを含む特定の最終位相を直接計算する可能性は残るが、単なる三値化では省略できない。

## 最初に試すもの：EEAの制御付き商の加算

公開参照コードの`accumulate_quotient`は、商を計算し、制御付きでq_iへXORし、
商と逆元の作業領域を清掃する。局所仕様を次に固定する。

\[
|a,b,t,c,0\rangle\longmapsto
|a,b,t\oplus c\,[a\,\operatorname{inv}(b)],c,0\rangle,
\qquad\operatorname{inv}(0)=0.
\]

a,b,tは12ビット、cは1量子ビット。tの初期値は任意であり、cも古典定数に限定しない。
新しい局所回路は、既存inverse66のforward、公開Kickmixの乗算、制御付きXOR、
乗算の測定清掃、inverse66のeraseを接続する。積を先に清掃し、その後に逆元と
保持した中間値を清掃する順序が必要である。

| 局所量 | 元の割り算ルーチン | 新しい局所候補 |
|---|---:|---:|
| 静的Toffoli数 | 390 | 141 |
| 局所量子ビット数（入力・出力を含む） | 109 | 82 |
| 保持する外部入力・出力 | 37 | 37 |

`quotient_probe.py`の厳密Boolean ANF検査は、37入力変数と108個の独立した測定結果を
扱い、全2^108測定分岐について上の仕様、残留位相ゼロ、作業領域ゼロを確認した。
HMRの位相補正を1つ削除した負例は拒否する。これはPythonの有限代数検査であり、
Leanカーネルによる証明ではない。Kickmixの構文解析も成功した。

保存した基準KMBの実際のINFO_TAGと命令を数えると、`quotient_div`は
forward EEAに444箇所、reverse EEAに444箇所あり、888箇所すべて390 Toffoliである。
最初のforward領域は命令区間[47422,53676)、reverse領域は[66843533,66849788)。
これらは基準KMBの0始まり区間であり、inverse66版の命令位置とは異なる。

## 改善余地の位置づけ

既存Forney置換後の静的Toffoli数4,705,806のうち、EEA往復は4,218,900（約89.65%）。
この89.65%は残存費用の割合であり、削減可能率ではない。

888箇所をすべて同じ条件で置換できれば、静的な見積もりは

\[
\Delta T=888(390-141)=221112,\qquad
T'=4705806-221112=4484694.
\]

現在の候補に対する追加削減は静的Tで約4.70%。全体Q、実行条件付き平均T、
誤り率の項を測っていないため、公式スコア改善や総量子ビット27個削減とは主張しない。

| 優先順 | 方向 | 現在の判断 |
|---|---|---|
| 1 | EEA内の商加算ブロックを1箇所置換 | 局所仕様の検査済み。実配線の監査へ進む |
| 2 | EEAの繰り返し乗算・条件付き交換を減らす | 正確な呼出し回数と実行条件を調べてから選ぶ |
| 3 | EEA制御状態の要約・統合 | 到達可能性と後続操作に対する要約の整合性を証明するまで保留 |

## 次の統合条件と検証順

1. 完全DQIの1つの`quotient_div`について、a,b,t,c、逆元、商、作業領域、
   古典一時ビットを実オペランドから対応付ける。相互の重複、入口ゼロ、外側の条件、
   私有測定ビットの寿命を確認する。局所回路のビット番号をそのまま転用しない。
2. 既存の乗算生成器は旧scaffoldをdirty workspaceとして借りられるため、
   旧逆元だけを無条件に差し替えず、商加算ブロック全体の契約を保存して置換する。
3. 未変更部分をバイト比較し、名前付きレジスタとQを監査する。
4. 完全な1箇所候補で既存Actionsのcandidate→smoke→full-packageを実行する。
   その後に888箇所へ広げ、現行Forney置換候補を比較対象として再測定する。
5. 公式依存ファイルを取得できない段階はNOT_RUNとする。Kaggle提出は自動実行しない。

## 1箇所統合チェックポイント

`quantum/eea_quotient_dqi.py`は検証済みForney版のハッシュを固定し、旧商加算の
全命令を公開生成器の109量子ビット・13古典ビットのテンプレートに照合する。
量子・古典それぞれで単射なオペランド対応を要求し、別ゲート、別配線、重複を拒否する。
初めて使うパリティビットと再利用するパリティビットで、初回参照直前の
`BIT_STORE0`が1つだけ異なる。両方の旧回路を同じ仕様について厳密検査し、
その2種類だけを照合対象にする。全888箇所の事前監査は新規1箇所・再利用887箇所で成功した。
さらに完全回路を後ろ向きに解析し、旧測定ビットが上書き前に参照されないことを
条件分岐の非実行経路も含めて確認する。旧入口の72個のRを保存する。

| 最初の箇所の外部役割 | forward EEA | reverse EEA |
|---|---|---|
| 分子a | q1740..1751 | q876..887 |
| 分母b | q828..839 | q840..851 |
| XOR先t | q1809..1820 | q1809..1803、q1826..1822（この順） |
| 量子制御c | q1805 | q1810 |

逆向きでは同じ役割でも配線番号・並びが異なるため、全位置の実命令から対応を取得する。

1箇所版はQ=1,893、古典ビット49,155、名前付きレジスタ4,165を維持し、
静的Toffoli数4,705,557、SHA-256
`90e27bf5ecc872dddf6ba8bf244226b33bd009ec334eeb9e0ca1ee298ef3e238`となった。
対象外の命令・オペランド・レジスタ・残すメタデータのバイト一致と、完全Kickmix解析を確認。
公開DQI検証器の1,536ショットで値・位相の誤り0、log2_delta=-128のsmokeを通過した。
[1箇所の記録](../../checkpoints/eea-quotient-one-site-20261026.json)を参照。

既存Actionsは1箇所でcandidate→smoke→full-packageを通した後に全888箇所へ広げる。
`--comparison`を指定したfull-packageは新候補と旧Forney版を同じ条件で102,400ショットずつ
検証し、追加のコスト削減がある場合だけZIPを作る。ZIPの残り12ファイルは引き続き
Release v1.0から保存する。必要な公式ファイルがない場合はNOT_RUNを記録し、拡大しない。
全箇所版のfull結果とKaggle公式スコアは、この時点では未確認。
旧Forney提出候補とRelease v1.0は変更しない。

## 再現

既存CIと同じQualtranコミット`638777fac4379bc62e2a1e4a52cf1a1753895d48`の
KickmixとNumPyを用い、リポジトリルートから実行する。

```bash
python research/eea_boolean/quotient_probe.py --baseline /path/to/baseline-dqi.kmb
```

`--baseline`を省略すると、局所回路の生成と厳密検査のみ行う。
コード、KMx、[検査結果](quotient-local-report.json)を同じ場所に保存する。
inverse66の分解と帰属情報は[既存記録](../inverse66/README.md)を継承する。
