# BM版DQI：清掃済みの演算補助3量子ビットをForneyで再利用

対象はPR #4の検証済みソース `332ba2f13ca7ec35e09d9703a7ce4fc5da148436`。記録のみを追加したPR先端 `902635162b7f4a937aa5b5ce566a8f3a4b26d20d` から、独立ブランチ `wfs/dqi-bm-scratch3-20261027` を作成した。元のソース、Release v1.0、既存候補と既存PRは変更していない。Kaggleへの公式提出は行わない。

## 割当てと生存期間

既存BuilderはLIFOの空きリストを持ち、`qubits` は空きを優先する。`release_recycle` は所有権を解放して空きリストへ戻すだけで、リセットや清掃命令を挿入しない。ゼロへの清掃は演算側の義務である。`reclaim` はBMの逆再生が必要とする元の物理IDを再確保し、使用中のIDでは失敗する。

| レジスタ | 幅 | 確保・保持・解放 |
| --- | ---: | --- |
| S0〜S69 | 840 | 最初に確保。基底変換、omegaの一時書換えと復元を経て、最後に入力状態へ戻る。外部レジスタとして保持 |
| Dw | 12 | `held` の先頭。BMの不一致値と逆再生に使用。今回は再利用しない |
| dW | 8 | `held` のカウンタ。BM後も逆再生まで保持。今回は再利用しない |
| sA/sB/sT | 3 | `held` の末尾。Emの各演算でゼロへ戻る。Forney中にEmの呼出しがないため貸し出す。所有権は `held` に残す |
| SIG | 36×12 = 432 | seed・各ラウンドの初回使用時に遅延確保。係数全域を保持。monicize→Forney→unmonicizeを経て、初回使用ラウンドの逆再生後に清掃・解放 |

BM順計算終了時の保持量は `840+23+432+444+665=2404`。ここまでの最大確保数は2440なので、清掃済みの36量子ビットが空いている。monicizeとomegaの終了時にも同じ2404量子ビットを保持する。旧Forneyの81量子ビットにはこの36本が既に利用されており、残り45本の追加でQ=2485となる。**81本全部を削減できるわけではない。**

## 今回の最小変更と清掃根拠

`forney_workspace` が78本を通常の割当器から取得し、`held[20:23]` の3本を末尾に加える。新しいリセット、測定、ゲートは追加しない。借りた3本を空きリストに入れたり所有権を解放したりしない。終了時はForneyが所有する78本だけを戻す。

旧 `q2482,q2483,q2484` を、Forneyの範囲内だけ `q860,q861,q862` に置換する。役割は根判定木の最後の2節点と、WFS位相核の補助ビットである。

- 貸出し前：Emの `pivot_pair` はsA/sBへの線形構築を逆順に取り消す。`fan_pair` はsTをHMRし、条件付きCZで測定依存位相を返済する。omega終了後の基底変換はこれら3本に触れない。
- 貸出し中：SIG/omegaとの重複はなく、Emは動かない。従来と同じForney回路を別の清掃済み3本に載せる。
- 返却前：根判定木は逆順のHMRとCZ返済で清掃される。WFS補助の清掃は既存の厳密検査 `verify_exact` が確認する。Forneyの逆元保持領域も従来のmatched forward/eraseで清掃される。
- 返却後：基底変換を戻し、omega_restore、unmonicize、BM.reverseへ進む。以降の量子配線と測定条件は旧版と一致することを全KMBパケットの比較で検査する。

35スロットの履歴、係数の範囲、任意の実行時Eマスク、Sの復元、清掃処理は維持する。BM全体の形式証明を追加したという意味ではない。

## 検証方法と再現

ローカルの33テストが通過した。追加テストは、借用中の所有権、ゲートを追加しないこと、78本だけの解放と割当順、別所有者・解放済み・重複配線の拒否、全パケット比較の成功、ゲート変更・古典条件変更の拒否を検査する。

`quantum/bm_scratch_audit.py` は旧回路のSHA-256を `107496dc7309eb15f227c80e7ed45b19dddb878b761ec5dc204db5ee812b7857` に固定する。命令、測定先、条件、タグ、名前付きレジスタ、Forney外の量子配線がすべて一致し、Forney内は指定の3本だけが置換されたことを検査する。原典vendorファイルは変更しない。

```sh
python -m unittest discover -s quantum -p 'test_*.py' -v
python research/bm_port/build_dqi.py --out build/bm-scratch3 --trace-allocations
python research/bm_port/build_dqi.py --out build/bm-scratch3 --parse
python quantum/bm_scratch_audit.py --reference build/input/bm-verified/dqi.kmb --candidate build/bm-scratch3/dqi.kmb --out build/report/scratch-correspondence.json
```

`--no-reuse-forney-scratch` で旧版の割当てを再現できる。`allocations.json` には確保・所有権取得・解放・再確保・フェーズ境界ごとに、物理ID、命令位置、Q、生存数、空き数、ピークを記録する。この記録は状態がゼロであることの量子シミュレーションではなく、割当てと所有権の追跡である。

GitHub Actionsはcandidate→smoke→full-package、深い履歴とEマスクの追加検査、13ファイルZIP照合を実行する。比較回路は検証済みBMアーティファクトを読み取り専用で取得する。最初の実行40386274898はアーティファクト読み取り権限不足で回路検証前に停止。`actions: read` を追加した実行40386467897で再検証中。

## EEA商加算120-Toffoli案との関係

| 要素 | 新BMでの扱い |
| --- | --- |
| EEAの888商加算位置を置換するパッチ | BMがEEA復号を置換したため、その888位置は新生成器の対象に存在しない。18,648演算の削減見込みをBMへ加算しない |
| 141→120の構成 | inverse66＋乗算63＋制御12を、inverse66＋乗算42＋制御12へ変える局所案。旧APIは制御付き `target ^= num*inv(den)` |
| 42積の双線形乗算 | 再利用可能な原理だが、BMは既に `KT12` の42積を使用。両JSONの全42項の一致も確認した。二重に削減を数えない |
| inverse66と測定後の位相返済 | BM側の反転鎖およびForneyの保持型inverse66にも関連する。Forneyのmatched eraseは今回変更しない |
| BM内の `quotient` | `p=Delta*sigma0` を作り、制御に応じてpとinv(p)を選ぶ別インターフェイス。銀行レジスタ更新後の情報からpを清掃するため、旧82ビット商加算回路をそのまま挿入できない |
| Boolean ANFと負例テスト | 局所演算の正しさ・清掃・測定位相の検査手法として再利用可能。新しい局所置換をする場合はBMの境界条件で証明し直す |
